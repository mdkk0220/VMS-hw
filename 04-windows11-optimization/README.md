# 4 · Windows 11 최적화 적용 및 테스트

> **개념 정리로 진행한 과제입니다.** 무엇을 왜 바꾸는지와 효과를 확인하는 방법을 정리했습니다.
> 자세한 설명은 [CONCEPTS.md](./CONCEPTS.md)에 있습니다.

## 한 줄 요약
VDI에서는 가상 PC 한 대의 낭비가 대수만큼 곱해지므로, 사용자가 복사해 쓰는 **골든 이미지**에 최적화를 한 번 적용합니다. 보안 항목(백신 · 방화벽 · 업데이트)은 끄지 않고 운영 방식만 바꿉니다.

---

## 1. 과제 요구사항과 결과

| 요구사항 | 결과 |
| --- | --- |
| OS 단 최적화 적용 | 개념 정리: 항목 10개와 각각의 이유 · 주의점 ([CONCEPTS](./CONCEPTS.md#최적화-항목-무엇을-왜)) |
| 최적화 효과 테스트 | 개념 정리: 적용 전후로 잴 항목 5개와 측정 명령 ([CONCEPTS](./CONCEPTS.md#효과는-어떻게-확인하나)) |

---

## 2. 핵심 정리

| 구분 | 내용 |
| --- | --- |
| 왜 하나 | 서버 한 대에 가상 PC 수십 대. 불필요한 서비스 하나가 수십 배로 곱해져 CPU · 메모리 · 디스크를 씀 |
| 어디에 적용하나 | 골든 이미지에 한 번 적용하고, 그 이미지로 가상 PC를 배포 |
| 주요 항목 | 시각 효과, 전원(`powercfg -h off`), 시작 프로그램, SysMain, 소비자용 서비스, DiagTrack, 기본 앱, 예약 조각 모음 |
| 끄지 않는 것 | 백신, 방화벽, 업데이트. 업데이트는 골든 이미지를 업데이트해 다시 배포하는 방식으로 관리 |
| 적용 전 | 스냅샷 · 복원 지점, 기준 수치 측정 |
| 효과 확인 | 프로세스 수, 실행 중 서비스 수, 유휴 메모리, 부팅 · 로그인 시간(이벤트 ID 100), 디스크 사용량 |
| 도구 | Microsoft [VDOT](https://github.com/The-Virtual-Desktop-Team/Virtual-Desktop-Optimization-Tool), Omnissa Horizon OSOT(롤백 파일 제공) |

## 3. 장애 장면으로 연결하기

**"가상 PC가 아침 9시마다 느려져요."** 같은 시각에 수십 대가 동시에 하는 일을 먼저 의심합니다. 로그인 폭주, 예약된 백신 검사, Windows Update, 조각 모음이 후보입니다. 가상 PC 한 대가 아니라 **서버(호스트)의 CPU · 디스크 I/O**를 함께 보고, 끄는 대신 시각을 분산하거나 골든 이미지에서 예약 작업을 정리합니다.

## 4. 한 문단 설명
VDI 환경에서 Windows 최적화는 가상 PC 한 대를 빠르게 하는 일이 아니라, 서버 한 대에 올라간 수십 대의 낭비를 줄이는 일입니다. 그래서 골든 이미지에 적용하고, 적용 전에 스냅샷과 기준 수치를 남긴 뒤 같은 방법으로 다시 재서 효과를 숫자로 확인합니다. 보안 항목은 최적화 대상이 아니며, 부하가 문제라면 끄지 않고 실행 시각을 분산합니다.
